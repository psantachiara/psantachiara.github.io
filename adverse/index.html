Adverse: An Inverse Ad Blocker

Pietro Santachiara

DescriptionThis Chrome extension shows advertisements and tracking entities while hiding the content of webpages. It is in this sense a tool for making the infrastructure visible: what the extension hides is what we normally read, and what it reveals is what normally reads us.
Type Chrome extension
Year 2026
Availability [Chrome Web Store, unlisted]
Source [forthcoming]

An ad blocker is a filter with a stated preference. It knows how to tell an advertisement from an article, a tracking script from a stylesheet, and it acts on that knowledge by subtraction: the page arrives, the unwanted elements are identified, and what remains is offered as the thing you came to read.

Adverse keeps the apparatus and reverses the preference. The same detection, the same classification, the same intervention in the page — applied the other way around. What a blocker removes, Adverse retains; what a blocker protects, Adverse removes.

What it does

  • Displays the advertisements present on a page, in place, rather than suppressing them.
  • Surfaces the tracking entities loaded by the page and makes them legible as entities.
  • Hides the editorial and interface content that would ordinarily be the object of reading.

Install

Adverse is distributed as an unlisted extension on the Chrome Web Store, which means it installs normally but is not publicly searchable. [Install link to follow.]
